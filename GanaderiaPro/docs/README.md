
# Documentación — GanaderíaPro

Esta carpeta contiene los documentos de análisis, planificación, diseño y seguimiento del proyecto GanaderíaPro, un sistema de gestión integral de ganado bovino desarrollado para la asignatura Proyecto de Sistemas II.

## Instrucciones de consulta

1. Seleccionar el documento requerido desde el índice.
2. Utilizar los enlaces para acceder a los archivos almacenados en el repositorio.
3. Descargar los documentos que necesiten una aplicación externa para su edición.
4. Consultar el historial de commits para identificar cambios anteriores.

## Buenas prácticas de mantenimiento

- Mantener actualizados los nombres y las descripciones de los documentos.
- Registrar los cambios mediante commits descriptivos.
- Realizar modificaciones en ramas de trabajo, evitando cambios directos sobre `main`.
- Utilizar Pull Requests para proponer y revisar mejoras.
- Verificar que los enlaces funcionen antes de integrar modificaciones.
- No publicar contraseñas, tokens ni información confidencial.

## Control de cambios

Las modificaciones documentales deben registrarse en GitHub para facilitar su revisión, colaboración y trazabilidad.

Este índice permite localizar los artefactos del proyecto y mantener organizada su documentación.

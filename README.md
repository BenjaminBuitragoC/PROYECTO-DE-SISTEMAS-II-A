# Sistema de Inventarios

Proyecto inicial del Equipo 3 para administrar productos, existencias y movimientos de almacén mediante un flujo de trabajo colaborativo en GitHub.

## Descripción

El sistema centraliza el registro de productos y permite controlar entradas, salidas y ajustes. También mantiene la trazabilidad de cada movimiento, facilita la consulta de existencias y muestra alertas cuando un producto alcanza su stock mínimo.

## Objetivo general

Desarrollar un sistema de inventarios que proporcione información confiable y actualizada sobre las existencias, reduzca errores manuales y facilite la reposición oportuna de productos.

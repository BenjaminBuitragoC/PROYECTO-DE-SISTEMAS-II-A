# PROYECTO-DE-SISTEMAS-II-A

Repositorio de los avances de proyectos de la materia Proyecto de Sistemas II.

## Propósito

Este repositorio centraliza los artefactos, avances y documentación de los equipos
de trabajo. Los documentos de apoyo se encuentran en `docs/` y los materiales
académicos originales permanecen en la raíz.

## Flujo de contribución

1. Partir de `main` actualizado.
2. Crear una rama descriptiva para el cambio.
3. Registrar commits pequeños y verificables.
4. Abrir un Pull Request hacia `main`.
5. Solicitar revisión a otro integrante.
6. Corregir las observaciones y fusionar únicamente después de la aprobación.

No se deben incluir contraseñas, tokens, claves privadas ni datos personales en
commits, documentos o ejemplos.

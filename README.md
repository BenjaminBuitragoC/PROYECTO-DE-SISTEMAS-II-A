# PROYECTO-DE-SISTEMAS-II-A

Repositorio de avances de proyectos de la asignatura Proyecto de Sistemas II.

## Uso del repositorio
- Consulta los documentos del curso y los artefactos compartidos por los equipos.
- Trabaja en una rama descriptiva para cada mejora.
- Registra los cambios con commits claros y propone su integración mediante Pull Request.
- No realices cambios directamente sobre `main`; solicita revisión antes de integrar.
- No publiques contraseñas, tokens, claves ni datos personales o confidenciales.

## Reutilización de documentación
La [guía de reutilización](docs/guia-reutilizacion.md) describe cómo adaptar plantillas y documentación para otros equipos, proponer mejoras y mantenerlas con revisión.

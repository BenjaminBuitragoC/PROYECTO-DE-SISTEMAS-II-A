# Sistema de Gestión Gastronómica

## Descripción

El Sistema de Gestión Gastronómica es una aplicación orientada a la administración de establecimientos de comida. Integra la gestión de pedidos, el control de inventario y la facturación en una única plataforma. Este proyecto se desarrolla en el marco de la asignatura Proyecto de Sistemas II.

## Objetivo general

Diseñar y desarrollar un sistema informático que permita gestionar de manera eficiente los procesos operativos de un establecimiento gastronómico, tales como el registro de pedidos, la administración del menú, el control de existencias y la emisión de comprobantes de pago, con el fin de reducir errores, optimizar los tiempos de atención y proporcionar información oportuna para la toma de decisiones.

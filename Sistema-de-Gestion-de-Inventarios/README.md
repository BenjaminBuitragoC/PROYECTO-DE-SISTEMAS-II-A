# Sistema de Gestión de Inventarios

## Descripción
Proyecto académico para registrar productos, entradas y salidas de almacén, consultar existencias y detectar niveles bajos de stock. Esta entrega contiene la estructura y documentación inicial del sistema.

## Objetivo general
Diseñar e implementar un sistema que permita controlar el inventario y mantener un historial de movimientos para reducir errores de registro y apoyar las decisiones de reposición.

# Sistema de Gestión de Colegio

## 1. Nombre del sistema

SistemaColegio – Sistema de Gestión Académica.

## 2. Descripción

Sistema orientado a la organización y administración de la información académica de una institución educativa. Permitirá gestionar estudiantes, docentes, cursos, matrículas y calificaciones.

## 3. Objetivo general

Diseñar y desarrollar un sistema de gestión académica que permita mejorar la organización de la información de estudiantes, docentes, cursos, matrículas y calificaciones de una institución educativa.

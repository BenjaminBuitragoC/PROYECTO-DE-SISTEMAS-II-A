# Guía de reutilización de requisitos

## 1. Descripción del recurso
Esta guía permite a otros equipos reutilizar una plantilla de requisitos funcionales para documentar sus sistemas de información.

## 2. Instrucciones de uso
1. Copiar la estructura de requisitos del proyecto SistemaColegio.
2. Adaptar los requisitos a las necesidades del nuevo proyecto.
3. Asignar un código a cada requisito (RF01, RF02, RF03).
4. Revisar y validar los requisitos antes de utilizarlos.

## 3. Reglas para proponer modificaciones
- Crear una rama para realizar cambios.
- Registrar las modificaciones mediante commits descriptivos.
- Crear un Pull Request explicando los cambios.
- Solicitar una revisión antes de integrar las modificaciones.

## 4. Responsables
- Elaboración y mantenimiento: José Andrés Huamaní.
- Revisión: integrante designado del equipo.
- Aprobación: responsable autorizado del proyecto.

## 5. Mantenimiento
La guía se actualizará cuando se identifiquen mejoras o nuevos requisitos. No se deben incluir datos confidenciales.

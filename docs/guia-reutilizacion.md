# Guía de reutilización de artefactos

## Propósito
Esta guía propone una forma común de compartir plantillas y documentación técnica entre equipos de Proyecto de Sistemas II. Cada equipo debe adaptar los ejemplos a su sistema y evitar incluir datos personales, credenciales, información institucional restringida o detalles internos que no sean necesarios.

## Recurso compartible
Se pueden reutilizar plantillas genéricas de requisitos, casos de prueba, instalación y documentación. Antes de publicar un artefacto, retirar nombres, direcciones, contraseñas, tokens, datos reales de usuarios y rutas locales. Usar valores ficticios y marcar los campos que debe completar cada equipo.

## Cómo reutilizarlo
1. Copiar el archivo pertinente al repositorio del equipo.
2. Crear una rama descriptiva para la adaptación.
3. Reemplazar los campos de ejemplo por información aprobada del proyecto.
4. Revisar que el documento sea claro, consistente y no contenga secretos ni datos sensibles.
5. Registrar los cambios en un commit descriptivo y proponerlos mediante Pull Request.

## Propuestas de modificación
- Abrir una incidencia o Pull Request que explique el problema o la mejora.
- Mantener el formato y el lenguaje comprensibles para otros equipos.
- No incluir credenciales, datos personales ni información confidencial.
- Adjuntar ejemplos ficticios cuando se necesiten datos de muestra.
- Solicitar revisión antes de integrar cambios; resolver observaciones en la misma rama.

## Revisión y mantenimiento
La persona responsable de documentación del equipo autor de la plantilla coordina su mantenimiento. Un integrante revisor valida claridad, utilidad y ausencia de información sensible. El docente o administrador conserva la decisión sobre cambios al repositorio del curso y sus permisos. Revisar las plantillas al inicio de cada nuevo proyecto o cuando cambien los requisitos de la asignatura.

## Historial
Las modificaciones deben conservar trazabilidad mediante ramas, commits descriptivos y Pull Requests revisados. No editar directamente la rama principal.

# Guía de reutilización y contribución

## Propósito

Esta guía ofrece una plantilla neutral para que los equipos documenten y compartan recursos técnicos reutilizables. No se deben incluir datos personales, credenciales, tokens, información interna ni contenido perteneciente a terceros sin autorización.

## Recursos que se pueden compartir

- Plantillas de requisitos y casos de prueba.
- Guías generales de instalación y ejecución.
- Ejemplos mínimos que no dependan de datos reales.
- Listas de verificación de revisión y seguridad.

Antes de publicar un recurso, el equipo autor debe comprobar que sea genérico, que los enlaces funcionen y que no contenga secretos ni datos del proyecto que deban mantenerse privados.

## Cómo reutilizar un recurso

1. Leer el propósito, los requisitos previos y la licencia o autorización indicada por el equipo autor.
2. Copiar el recurso a la documentación del proyecto que lo utilizará.
3. Adaptar nombres, rutas y ejemplos al sistema propio; no copiar credenciales ni datos reales.
4. Mantener una referencia al recurso de origen y anotar las adaptaciones relevantes.
5. Revisar el recurso antes de cada entrega para confirmar que sigue siendo aplicable.

## Cómo proponer cambios

1. Crear una rama descriptiva a partir de la rama principal actualizada.
2. Realizar cambios acotados y registrar commits con mensajes claros.
3. Abrir un Pull Request que explique el motivo, el alcance y la forma de verificar el cambio.
4. Solicitar revisión de otra persona del equipo responsable del recurso.
5. Resolver observaciones y actualizar el Pull Request; integrar solo después de la aprobación requerida.

## Responsables

- Equipo autor: valida el contenido y responde a las revisiones.
- Revisor designado: comprueba claridad, seguridad, enlaces y que los ejemplos sean reproducibles.
- Responsable de documentación del equipo: mantiene la versión vigente y registra cambios relevantes.

Los nombres de responsables se deben acordar en cada equipo y documentar en su propio proyecto; esta guía no asigna permisos ni responsables reales.

## 1. Nombre del sistema

**Sistema Hospitalario** – Sistema de gestión de pacientes, citas médicas e historias clínicas.

## 2. Descripción

El Sistema Hospitalario es una aplicación orientada a centralizar y digitalizar los procesos
principales de un centro de salud: el registro de pacientes, la programación de citas con los
médicos, el registro de la historia clínica y el control de las atenciones realizadas.

Actualmente muchos de estos procesos se manejan en papel o en hojas de cálculo aisladas, lo que
provoca pérdida de información, tiempos de espera elevados y dificultad para consultar el
historial de un paciente. El sistema busca resolver estos problemas con una plataforma única,
segura y fácil de usar para el personal administrativo y médico.

## 3. Objetivo general

Desarrollar un sistema de información que permita gestionar de forma integrada los pacientes,
médicos, citas e historias clínicas de un centro de salud, con el fin de reducir los tiempos de
atención y mejorar la disponibilidad y seguridad de la información.

### Objetivos específicos

- Registrar y actualizar los datos de pacientes y médicos.
- Programar, reprogramar y cancelar citas médicas según la disponibilidad de cada especialidad.
- Registrar las atenciones y mantener la historia clínica de cada paciente.
- Generar reportes básicos de atenciones y citas.

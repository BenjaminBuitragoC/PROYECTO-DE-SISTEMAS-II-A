Pruebas unitarias, de integración y de aceptación del **Sistema Hospitalario** (citas / pacientes).

## Ejecutar

Desde `sistema-hospitalario/`:

```bash
node tests/practica3/unitarias/run_all.js
node tests/practica3/integracion/run_ej4_ej5_ej6.js
```
